# Тестовая версия сайта avd-analytics.ru

Обновлённая версия подготовлена в отдельной рабочей ветке для проверки на `test.avd-analytics.ru`. Существующая версия на `main` не меняется. Не направляйте production-домен на эту ветку и не переключайте источник публикации действующего сайта.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Тестовая главная: аудит, проекты, цены, FAQ и контакты |
| `offer.html` | Условия оказания услуг |
| `privacy.html` | Политика обработки персональных данных |
| `css/style.css` | Оформление главной и документов |
| `js/main.js` | Яндекс Метрика, cookie-баннер, цели, мобильное меню и окно контактов |
| `images/` | Логотип, фотографии и иконки |
| `sitemap.xml`, `robots.txt` | SEO-файлы тестового поддомена |
| `llms.txt` | Краткая справка об услугах |

## Тестовый поддомен

Тестовая публикация размещена отдельно в публичном репозитории [`nejasit77-afk/avd-analytics-test`](https://github.com/nejasit77-afk/avd-analytics-test). GitHub Pages включён для ветки `main`, каталога `/`; файл `CNAME` содержит `test.avd-analytics.ru`. Настройки и файлы production-сайта не затронуты.

Чтобы поддомен открывал GitHub Pages, в DNS-зоне Timeweb удалите только существующую запись типа `A` для имени `test` (сейчас она указывает на `92.53.96.201`, парковочную страницу Timeweb) и создайте:

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `test` | `nejasit77-afk.github.io` |

Не меняйте DNS-записи корневого домена `avd-analytics.ru` или текущего production-сайта. После распространения DNS проверьте, что CNAME указывает на `nejasit77-afk.github.io`, дождитесь выпуска сертификата в настройках GitHub Pages тестового репозитория, затем включите **Enforce HTTPS**. Тестовая главная и оферта закрыты от индексации (`noindex`).

На время теста главная и оферта содержат `noindex`; канонический адрес, Open Graph, sitemap и `robots.txt` указывают на тестовый поддомен. Перед переносом на основной домен обновите эти адреса и снимите `noindex`.

## Яндекс Метрика

Счётчик `113719924` и поведение cookie-баннера сохранены. Цели на клики:

| Идентификатор | Срабатывает при |
|---|---|
| `click_order` | Открытие окна выбора связи. Параметр `service` содержит идентификатор услуги |
| `click_telegram` | Переход в Telegram |
| `click_max` | Переход в MAX |
| `click_phone` | Клик по телефону |
| `click_email` | Клик по почте |

В `service` передаются `header_contact`, `hero_audit`, `hero_free_call`, `pains_cta`, `audit`, `audit_tz`, `setup`, `monitoring`, `consultation`, `ux_review`, `cjm`, `calls_review`, `ecommerce`, `support`, `agency_audit` и `checklist`.

## Перед публичной публикацией

- Проверьте согласованность страниц `index.html`, `offer.html`, `privacy.html` и правовую применимость текстов оферты.
- Подтвердите актуальность ИНН, контактных данных, инструментов и перечисленных результатов проектов.
- Замените демонстрационный фрагмент отчёта обезличенным скриншотом настоящего отчёта, когда он будет готов. Пока он явно помечен как демонстрационный; ссылок на отсутствующий PDF нет.
- В январе 2027 года сезонный баннер скрывается автоматически.
